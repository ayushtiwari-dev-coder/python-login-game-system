# Python Login Game System

A command-line Python login system with session management and a Rock Paper Scissors game.

## Features

- User account creation
- Password hashing using SHA256
- Account lock after multiple failed login attempts
- Session management
- Rock Paper Scissors game with multiple modes

## Project Structure

```
login_system/
│
├── data/                  # Stores user data
├── rock_paper_scissor/    # Game logic
├── file_handler.py        # Handles reading/writing files
├── login_logic.py         # Login and account creation
├── session_manager.py     # Session management
├── main.py                # Main program entry
```

## How to Run

Run the program using:

```
python main.py
```
